# CSCI160-CH02-EXERCISES
Programming Exercises From Java Illuminated Book by Anderson and Franceschi  
**Before You Begin**  
In the terminal, enter: *sdk install java 17.0.9-ms*, and when prompted, press Y to set Java 17 as default.  
Then, in the search bar at the top, go to *>Java: Configure Java Runtime*  and change the Classpath JDK to Java SE-17 and the Compiler ByteCode to 17.  
GitHub Codespaces defaults to Java 11, so sometimes we need to change our configuration before we start coding.
